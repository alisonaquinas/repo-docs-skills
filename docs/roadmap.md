# Delivery Roadmap

## Phase 1 — Repository Skeleton ✅

Establish root scaffolding, docs/ llm-wiki structure, Obsidian vault config,
and linting split.

## Phase 2 — Core Skills (planned)

Author the first set of skills covering:
- `well-documented` — guide for maintaining living documentation
- `markdown-linting` — vanilla markdownlint setup and configuration
- `obsidian-flavored-markdown` — OFM wiki conventions

## Phase 3 — Hooks (planned)

CI and pre-commit hooks enforcing documentation quality gates.

## Phase 4 — Commands (planned)

Slash commands for common documentation tasks: audit, sync, generate.

## Phase 5 — Agents (planned)

Multi-step documentation agents: full-repo audit, wiki-sync, onboarding
doc generation.
